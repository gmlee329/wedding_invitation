# 참고 사이트 정렬형 모바일 청첩장 전면 재디자인 설계

작성일: 2026-07-20
참고 화면: https://w.theirmood.com/card/33zIhO4Sun

## 1. 목표

기존 모바일 청첩장의 기능과 배포 제약을 모두 유지하면서, 참고 사이트의 편집 디자인·여백·타이포그래피·화면 전환 방식을 기준으로 화면 전체를 다시 설계한다.

구현 결과는 다음 조건을 만족해야 한다.

- 실행 코드는 루트의 단일 `index.html`에만 둔다.
- `file://`로 `index.html`을 직접 열어도 동작한다.
- GitHub public repository와 GitHub Pages에 그대로 배포할 수 있다.
- 사진과 영상은 `assets/images/`, `assets/video/` 안의 파일만 교체해 변경할 수 있다.
- 이름, 날짜, 주소, 문구, 링크, 미디어 경로, 테마 값은 `index.html` 상단의 `WEDDING_CONFIG`에서 수정한다.
- 각 섹션은 `WEDDING_CONFIG.sections`의 불리언 값으로 독립적으로 표시하거나 숨길 수 있다.
- 페이지 진입 시 인트로 영상을 재생하며, 종료·스킵·오류 시 본문으로 자연스럽게 이어진다.
- 기존 연락처, 달력·카운트다운, 갤러리·라이트박스, 길찾기, 계좌 복사, 공유 기능과 접근성을 보존한다.

## 2. 참고 사이트 분석 결과

공개된 렌더링 결과와 브라우저에서 계산된 스타일을 기준으로 다음 특성을 디자인 기준으로 삼는다.

- 데스크톱 외부 배경은 약 `#eeeeee`이며, 콘텐츠는 너비 `425px`의 흰색 모바일 카드로 중앙 정렬된다.
- 모바일에서는 카드가 화면 너비를 채우며 데스크톱과 동일한 세로 흐름을 유지한다.
- 본문은 약 `#fafafa`의 따뜻한 종이색 위에 매우 약한 반복 질감을 사용한다.
- 첫 화면은 대형 고대비 세리프 영문, 겹쳐진 세로 사진, 원형 장식, 작은 영문 문구로 구성된다.
- 섹션 사이의 여백이 크고, 섹션 표제는 작은 대문자와 넓은 자간을 사용한다.
- 한글 본문은 가늘고 단정하며 버튼과 구분선은 시각적으로 절제되어 있다.
- 참고 사이트의 오프닝은 고정 오버레이와 이미지 애니메이션으로 약 5초간 진행되고, 우측 상단에 반투명 스킵 버튼이 있다.

이번 구현에서는 마지막 항목을 그대로 복제하지 않고, 사용자가 요구한 **동영상 인트로**를 유지한 채 같은 종이 캔버스·구도·전환 리듬으로 재해석한다. 참고 사이트의 소스 코드, SVG, 배경 이미지, 사진 등 전용 에셋은 복사하지 않는다.

## 3. 선택한 구현 접근

현재의 바닐라 HTML/CSS/JavaScript 구조와 설정 기반 렌더러를 유지하고, 마크업 구조와 CSS 비주얼 시스템을 전면 교체한다.

### 선택 이유

- 단일 파일과 `file://` 실행 조건을 가장 안정적으로 지킨다.
- 기존 기능과 섹션 토글 계약을 보존하면서 시각 구조만 크게 바꿀 수 있다.
- 대형 프레임워크 없이도 참고 사이트의 레이아웃과 전환을 충분히 재현할 수 있다.
- 외부 라이브러리 장애가 핵심 기능 장애로 이어지지 않는다.

### 외부 리소스 정책

로컬 실행 중 인터넷 연결을 통해 CDN 리소스를 내려받는 것은 허용한다. 이는 2026-07-20 사용자가 "로컬 실행도 외부 라이브러리 다운로드 되니까"라고 명시적으로 승인한 범위이며, 기존 설계의 런타임 외부 리소스 금지 조건을 이 항목에 한해 대체한다. 다만 핵심 동작은 외부 JavaScript에 의존하지 않는다.

- 라틴 디스플레이 글꼴: Google Fonts의 `Cormorant Garamond`
- 한글 본문 글꼴: Google Fonts의 `Gowun Dodum`
- 일반 UI 글꼴: jsDelivr의 Pretendard 웹폰트
- 모든 글꼴에는 `Georgia`, Apple 시스템 한글 글꼴, `sans-serif` 폴백을 둔다.
- 갤러리, 모달, 인트로 전환, 공유 기능은 기존 바닐라 JavaScript로 구현한다.
- 지도 SDK, Kakao SDK, YouTube API, particles.js, GSAP, Swiper 등은 요구 기능에 필요하지 않으므로 추가하지 않는다.

기존의 "외부 스타일시트 금지" 테스트는 삭제하는 대신, 위 세 글꼴 제공처만 자동 로드 리소스로 허용하는 허용 목록 테스트로 교체한다. 사용자가 눌러 이동하는 네이버·카카오·티맵 길찾기 링크와 공유 URL은 자동 로드 리소스가 아니므로 이 허용 목록의 대상이 아니다.

인터넷이 없을 때는 글꼴만 시스템 폴백으로 바뀌며, 콘텐츠·영상·버튼·갤러리·공유는 계속 동작해야 한다.

## 4. 전체 화면 구조

### 4.1 외부 캔버스

- `body` 배경은 `#eeeeee`로 설정한다.
- 앱 루트는 기본 최대 너비 `425px`, 최소 높이 `100svh`, 가로 중앙 정렬이다.
- 앱 루트 배경은 `#fafafa`이며, CSS 그라디언트로 만든 미세한 종이 섬유와 점 형태의 반복 질감을 겹친다.
- 실제 이미지 텍스처를 필수로 만들지 않아 미디어가 비어 있어도 완성된 배경을 유지한다.
- `WEDDING_CONFIG.theme.maxWidth`는 계속 편집 가능하되 기본값을 `425px`로 변경한다.

### 4.2 타이포그래피

- 대형 영문: `Cormorant Garamond`, 높은 대비, 얇은 웨이트, 촘촘한 줄 높이.
- 한글 본문: `Gowun Dodum`, 넉넉한 행간.
- 버튼·보조 정보: `Pretendard`, 작은 크기와 명확한 대비.
- 섹션 라벨: 10–11px, 대문자, `0.22em` 이상의 자간.
- 장식용 영문은 콘텐츠를 대체하지 않으며 한글 제목과 접근성 텍스트를 함께 유지한다.

### 4.3 간격과 장식

- 섹션 상하 여백은 모바일 기준 약 96–132px 범위로 사용한다.
- 굵은 카드 테두리 대신 1px 구분선, 가는 괄호형 프레임, 작은 원형 인덱스를 사용한다.
- 색상은 종이색, 먹색, 세이지 그린, 말린 장미색, 옅은 금갈색으로 제한한다.
- 그림자 사용을 최소화하고 사진 겹침과 여백으로 깊이를 만든다.

## 5. 인트로 영상과 본문 연결

### 5.1 동일한 배경 캔버스

인트로는 검은 전체 화면이 아니라 본문과 같은 구조를 사용한다.

- 화면 전체 고정 레이어의 바깥쪽은 `#eeeeee`.
- 내부에는 본문과 동일한 최대 너비 `425px`의 종이 카드가 중앙에 놓인다.
- 종이 카드에는 본문과 동일한 `#fafafa` 색상과 동일한 CSS 질감을 적용한다.
- 따라서 영상 로딩 전, 재생 중, 종료 후 어느 순간에도 검은색 또는 순백색 플래시가 나타나지 않는다.

### 5.2 영상 프레임

- 영상은 카드 전체를 무조건 채우지 않고, 히어로 사진과 같은 세로 비율의 편집형 프레임에 배치한다.
- 기본 `object-fit`은 `cover`이며, 사진·영상의 초점 위치는 설정값으로 조절할 수 있다.
- 영상 바깥에는 큰 세리프 문구, 작은 날짜 라벨, 얇은 선을 배치해 참고 사이트의 오프닝 리듬을 만든다.
- 영상이 없거나 재생에 실패하면 동일 프레임에서 포스터 또는 CSS 플레이스홀더를 보여준다.

### 5.3 스킵과 자동 완료

- 우측 상단 스킵 버튼은 카드 기준 상단 20–24px, 우측 20px에 고정한다.
- 배경은 `rgba(0, 0, 0, 0.4)`, 모서리는 8px, 텍스트는 14px로 구성한다.
- 영상의 `ended`, 스킵 클릭, 로딩 오류, 자동 재생 차단은 모두 하나의 종료 함수로 모은다.
- 중복 클릭이나 여러 이벤트가 발생해도 전환은 한 번만 실행한다.

### 5.4 자연스러운 크로스페이드

- 본문은 인트로 뒤에서 미리 렌더링한다.
- 인트로 카드와 히어로가 같은 배경 변수와 미디어 프레임 비율을 공유한다.
- `hero`가 활성화된 경우 종료 시 약 `650ms` 동안 인트로의 불투명도와 약한 확대를 줄이고, 히어로의 불투명도와 위치를 복원한다.
- `hero`가 비활성화된 경우에도 인트로는 같은 종이 캔버스 위에서 사라지고, 첫 번째 활성 섹션 또는 활성 섹션이 하나도 없으면 앱 루트를 전환·포커스 대상으로 삼는다. 특정 섹션의 존재를 전제하지 않는다.
- 전환 완료 뒤에만 인트로를 `hidden`/`inert` 처리하고 본문의 `aria-hidden`과 `inert`를 해제한 뒤 전환 대상에 포커스를 이동한다.
- `prefers-reduced-motion: reduce`에서는 전환 시간을 사실상 제거한다.

## 6. 섹션별 전면 재디자인

렌더링 순서는 참고 사이트의 서사 흐름에 가깝게 다음과 같이 정리한다. 각 섹션의 설정 키와 독립 토글은 그대로 유지한다.

1. **Hero** — `BEGINS / ON {MONTH}` 형태의 대형 영문, 세로 메인 사진, 원형 `JOIN US` 장식, 이름과 날짜.
2. **Invitation** — 작은 영문 라벨, 초대 문구, 넓은 여백, 얇은 식물형 CSS 장식.
3. **Couple** — 신랑·신부 이름과 부모 정보, 각 연락 버튼을 좌우 대칭이 아닌 편집형 두 단 구조로 배치.
4. **Schedule** — 월 표제, 미니멀 달력, 예식일 강조, D-day 카운트다운.
5. **Story** — 번호가 붙은 세로 사진과 문구가 번갈아 나타나는 에디토리얼 타임라인.
6. **Location** — 장소·주소를 크게 보여주고 지도 이미지 또는 플레이스홀더를 전체 폭에 배치.
7. **Transportation** — 지하철·버스·주차 정보를 가는 선으로 구분한 텍스트 목록.
8. **Gallery** — 서로 다른 비율의 모자이크 그리드와 기존 접근 가능한 라이트박스.
9. **Notices** — 필요한 공지 카드만 간결하게 렌더링.
10. **Accounts** — 기본은 닫힌 아코디언, 신랑측·신부측 계좌 복사 버튼 보존.
11. **Share** — 링크 복사와 Web Share API 버튼, 실패 시 폴백 안내.
12. **Outro** — 큰 영문 마감 문구, 날짜와 이름, 종이 여백으로 종료.

인트로, 영웅 화면, 초대 문구, 연락처, 일정, 스토리, 갤러리, 위치, 교통, 공지, 계좌, 공유, 아웃트로는 각각 기존 `sections` 키로 제어한다. 숨긴 섹션은 빈 여백이나 구분선을 남기지 않는다.

## 7. 설정과 미디어 교체 계약

`WEDDING_CONFIG`를 문서 상단의 유일한 콘텐츠 편집 지점으로 유지하고 주석을 섹션 순서와 맞춘다. 기존 키를 이름 변경하거나 재편하지 않으며, 현재 데이터를 그대로 사용해 새 레이아웃을 렌더링한다.

- `sections`: 섹션별 표시 여부
- `theme`: 기존 색상과 최대 너비를 유지하고 `transitionMs`만 선택적으로 추가
- `intro`: 기존 영상, 포스터, 라벨, 제목, 음소거, 폴백 시간에 `objectPosition`만 선택적으로 추가
- `couple`, `wedding`: 이름, 연락처, 날짜, 장소, 주소
- `messages`: 히어로·초대·아웃트로 문구와 서명
- `media`: 히어로, 지도, 갤러리 이미지 경로와 대체 텍스트
- `story`, `transportation`, `notices`, `accounts`: 각 섹션의 기존 배열 데이터
- `navigation`: 네이버·카카오·티맵 길찾기 링크
- `sharing`: 공유 제목과 본문

새 시각 옵션인 `theme.transitionMs`와 `intro.objectPosition`이 없으면 각각 `650`과 `50% 50%`를 기본값으로 사용한다. 즉 기존 `WEDDING_CONFIG`도 호환되며, 데이터 마이그레이션 없이 렌더링할 수 있어야 한다.

이미지 파일은 `assets/images/`, 인트로 영상은 `assets/video/`의 상대 경로를 기본값으로 사용한다. 파일을 바꿀 때 HTML 내부 렌더링 코드를 수정할 필요가 없어야 한다.

## 8. 오류 처리와 접근성

- 영상 자동 재생을 위해 `muted`, `playsinline`, `autoplay`를 사용한다.
- 영상이 재생되지 않아도 스킵 버튼과 짧은 폴백 타이머로 본문 진입을 보장한다.
- 이미지 오류는 비율이 유지되는 종이색 플레이스홀더와 대체 텍스트로 대체한다.
- 모달은 `dialog`를 사용하고 열기 전 포커스를 기억해 닫을 때 되돌린다.
- 인트로가 열린 동안 본문은 `inert` 및 `aria-hidden` 상태를 유지한다.
- 인트로가 열리면 SKIP 버튼으로 초기 포커스를 옮기고, `Escape` 키도 스킵과 동일한 단일 종료 함수를 호출한다.
- 종료 순서는 본문 접근성 상태 복원, 인트로 숨김, 첫 활성 콘텐츠 포커스 이동으로 고정한다.
- 종료 또는 재초기화 시 인트로 전용 `keydown` 리스너와 타이머를 반드시 정리해 중복 실행을 막는다.
- 모든 버튼은 최소 44px 터치 영역과 분명한 포커스 링을 가진다.
- 색 대비, 의미 있는 제목 구조, `aria-live` 안내, 키보드 조작을 보존한다.
- 모션 감소 설정에서는 자동 스크롤, 확대, 긴 크로스페이드를 제거한다.

## 9. 검증 전략

기존 테스트를 유지하고 새 디자인 계약을 테스트 우선으로 추가한다.

### 정적 계약

- 런타임 코드가 `index.html` 하나인지 확인한다.
- 미디어 경로가 지정 폴더를 사용하는지 확인한다.
- 모든 기존 섹션 토글과 설정 키가 유지되는지 확인한다.
- 문서 로드 시 자동 요청하는 외부 리소스는 승인된 글꼴 CDN만 사용하는지 확인한다. 길찾기·공유처럼 사용자가 클릭하는 외부 링크는 별도 검증한다.
- `425px`, `#eeeeee`, `#fafafa`, 공용 종이 배경 변수 등 핵심 레이아웃 토큰을 확인한다.
- 인트로와 본문이 동일한 캔버스·미디어 비율 변수를 공유하는지 확인한다.
- 스킵 버튼의 위치, 크기, 반투명 배경 계약을 확인한다.
- 본문 섹션 순서가 설계와 일치하는지 확인한다.

### 동작 계약

- 영상 종료, 스킵, 오류, 자동 재생 실패가 모두 동일한 단일 전환으로 이어지는지 확인한다.
- 중복 종료 이벤트가 전환을 반복하지 않는지 확인한다.
- 인트로가 사라진 뒤 포커스와 스크롤 상태가 정상인지 확인한다.
- 설정 변경, 섹션 숨김, 누락 미디어가 런타임 오류를 만들지 않는지 확인한다.
- `intro=true/hero=false`, `intro=false`, 모든 선택 섹션 비활성화 등 주요 토글 조합에서 안전하게 초기화되는지 확인한다.
- `Escape`, SKIP 초기 포커스, 본문 `inert`/`aria-hidden` 복원, 키다운 리스너 정리를 확인한다.
- `prefers-reduced-motion`에서 즉시 전환하고 불필요한 모션을 만들지 않는지 확인한다.
- 날짜 계산, 계좌 복사, 공유 폴백, 갤러리 라이트박스의 기존 테스트를 모두 통과한다.

### 수동 시각 검증

- 360px와 390px 모바일에서 수평 스크롤이 없고, 1280px 데스크톱에서 카드 폭과 중앙 정렬이 맞는지 확인한다.
- 인트로 재생 중 배경과 본문 배경이 동일하게 보이는지 확인한다.
- 종료 순간 검정/흰색 플래시 없이 히어로로 이어지는지 확인한다.
- 영상·사진이 없는 초기 저장소 상태에서도 레이아웃이 완성된 형태인지 확인한다.
- 글꼴 CDN을 차단한 오프라인 상태에서도 시스템 글꼴 폴백과 모든 기능이 정상인지 확인한다.
- 키보드만으로 인트로 Escape 종료, 모달 열기·닫기, 포커스 복귀가 가능한지 확인한다.
- `prefers-reduced-motion` 에뮬레이션에서 긴 전환과 확대가 제거되는지 확인한다.
- `file://` 직접 실행, 간단한 정적 서버, GitHub Pages 하위 경로 형태의 base URL에서 상대 미디어 경로를 각각 확인한다.
