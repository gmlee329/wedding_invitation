# 아이콘 전용 인트로 재생 버튼 디자인

## 목표

아이폰에서 인트로 영상 자동재생이 차단되면 설명 문구 없이 재생 아이콘만 표시한다. 버튼은 청첩장 화면에 어울리는 가벼운 흰색 원형으로 보이며, 누르면 기존 수동 재생 동작을 그대로 수행한다.

## 화면 디자인

- 버튼은 영상 중앙에 배치한 64×64px 원형이다.
- 배경은 흰색, 아이콘은 짙은 회색으로 표시한다.
- 얇은 반투명 테두리와 두 단계의 부드러운 그림자로 화면 위에 살짝 떠 있는 깊이감을 준다.
- 재생 아이콘은 글꼴 문자가 아니라 인라인 SVG를 사용해 기기별 모양 차이를 없앤다.
- 터치 중에는 버튼이 약간 작아지며, 키보드 포커스에는 명확한 외곽선을 표시한다.
- 기존의 `영상 재생`, `자동재생이 안 되면 한 번 눌러주세요` 문구와 관련 마크업·스타일을 제거한다.

## 동작과 접근성

- 자동재생 성공 시 버튼은 계속 숨겨진다.
- 자동재생 거부 시 아이콘 버튼만 표시되고 포커스가 버튼으로 이동한다.
- 버튼을 누르면 기존과 동일하게 영상을 다시 재생한다.
- 수동 재생도 실패하면 기존 미디어 오류 및 청첩장 진입 경로를 유지한다.
- 화면에는 글자를 표시하지 않지만 버튼의 `aria-label="인트로 영상 재생"`은 유지한다.
- 상태 알림 영역에는 자동재생 안내 문구를 넣지 않는다.

## 변경 범위

- `index.html`: 버튼 마크업, 버튼 CSS, 수동 재생 상태 문구만 변경한다.
- 영상 파일, 자동재생 시도, 재생 실패 처리, SKIP 버튼에는 손대지 않는다.

## 검증

- 소스 테스트로 설명 문구와 기존 텍스트용 클래스가 없고, 접근성 이름과 SVG 아이콘이 존재하는지 확인한다.
- 기존 수동 재생 테스트로 자동재생 거부 후 버튼 표시 및 터치 재생이 유지되는지 확인한다.
- 전체 웹 테스트를 실행한다.
- 모바일 크기에서 원형 버튼의 위치, 색상, 그림자와 텍스트 부재를 시각적으로 확인한다.
