# 모바일 청첩장 인트로·영상·모션·색상 개선 디자인

## 목표

아이폰에서 인트로 영상이 자동 또는 수동으로 자연스럽게 시작되도록 유지하면서 인트로와 본문의 전환을 더 부드럽고 분명하게 만든다. 영상 가장자리의 검은 선을 원본 처리 단계에서 제거하고, 전체 청첩장을 밝은 미스트 세이지 팔레트로 통일한다.

## 인트로 전환

- `Gyumin & Sara` 첫 문구는 1초 동안 유지한 뒤 약 1.2초 동안 페이드아웃한다.
- 문구 페이드아웃과 영상 페이드인을 동시에 시작해 교차 전환으로 보이게 한다.
- 영상 재생 성공 이벤트가 들어오면 영상이 드러나고, 문구는 전환이 끝난 뒤 접근성 트리에서 숨긴다.
- `prefers-reduced-motion: reduce` 환경에서는 전환 시간을 0으로 줄이되 자동·수동 재생 흐름은 유지한다.

## 수동 재생 버튼

- 자동재생이 거부되면 설명 문구 없이 영상 중앙에 64×64px 원형 재생 버튼만 표시한다.
- 버튼 배경은 흰색, 아이콘은 `#263b3b`이며 얇은 반투명 테두리와 두 단계의 부드러운 그림자를 적용한다.
- 재생 아이콘은 기기별 글꼴 차이가 없는 인라인 SVG로 표시한다.
- 터치 중에는 버튼이 약간 작아지고 키보드 포커스에는 명확한 외곽선을 표시한다.
- 기존의 `영상 재생`, `자동재생이 안 되면 한 번 눌러주세요` 문구와 관련 텍스트 마크업·스타일·상태 문자열을 제거한다.
- 화면에는 글자를 표시하지 않지만 `aria-label="인트로 영상 재생"`은 유지한다.

## 영상 가장자리 수정

- 원본 영상의 실제 그림 영역 가장자리에 1px 어두운 테두리가 있으며, 기존 `crop=840:720:222:0`이 이 테두리를 포함하는 것이 검은 선의 원인이다.
- 각 가장자리에서 1px 안쪽인 `crop=838:718:223:1`을 사용하고 Lanczos 방식으로 `840×720`에 맞춘다.
- 무음 H.264 Constrained Baseline Level 3.1, 24fps, 6초, `yuv420p`, faststart 조건은 유지한다.
- 첫 프레임에서 포스터를 다시 생성해 영상과 같은 무테두리 화면을 사용한다.
- `intro.original.mp4`는 수정하지 않는다.

## 본문 등장 모션

- 섹션 전체가 한 번에 움직이는 현재 720ms 모션 대신 헤더와 본문을 나누어 단계적으로 보여준다.
- 섹션 헤더는 36px 아래에서 약 1.1초 동안 상승하며 나타난다.
- 섹션 본문은 0.18초 뒤에 30px 아래에서 약 1.25초 동안 상승하며 나타난다.
- 감속 곡선은 빠르게 튀지 않는 `cubic-bezier(0.22, 1, 0.36, 1)`을 사용한다.
- IntersectionObserver가 없거나 동작 줄이기가 설정된 환경에서는 콘텐츠를 즉시 표시한다.

## 색상 팔레트

- 전체 배경과 인트로 종이색: `#f7feff`
- 기본 글자: `#263b3b`
- 보조 글자: `#708484`
- 세이지 포인트: `#718f8a`
- 브론즈 포인트: `#967d70`
- 버튼, 카드, 구분선, 오버레이 등은 위 CSS 변수에서 파생해 기존 대비와 구조를 유지한다.
- 문서 설정값과 CSS 초기값을 모두 같은 팔레트로 바꿔 초기 렌더링과 JavaScript 적용 후 색상이 달라지지 않게 한다.

## 변경 범위

- `index.html`: 테마 설정, CSS 변수, 인트로 전환, 재생 버튼, 본문 등장 모션을 변경한다.
- `scripts/edit_intro_video.py`: 크롭과 리사이즈를 변경하고 무음 MP4와 포스터를 다시 생성한다.
- `tests/invitation.test.mjs`: 아이콘 전용 버튼, 교차 전환, 모션, 팔레트 계약을 검증한다.
- `scripts/test_intro_video_clean_title.py`: 검은 가장자리 부재와 새 크롭 기준을 검증한다.
- SKIP, 재생 실패 후 청첩장 진입, 원본 영상 보존 동작은 유지한다.

## 검증

- 소스 테스트로 설명 문구와 기존 텍스트용 클래스가 없고 접근성 이름과 SVG 아이콘이 존재하는지 확인한다.
- 자동재생 성공·거부·수동 재생 실패 테스트로 기존 복구 흐름이 유지되는지 확인한다.
- 영상 테스트로 원본 해시, 무음 단일 스트림, 코덱, 프레임 수, 크기, 키프레임, faststart와 가장자리 밝기를 확인한다.
- 전체 웹·영상 테스트와 영상 완전 디코딩을 실행한다.
- 모바일 크기에서 인트로 교차 페이드, 재생 아이콘, 영상 가장자리, 본문 상승 모션과 색상 조화를 시각적으로 확인한다.
