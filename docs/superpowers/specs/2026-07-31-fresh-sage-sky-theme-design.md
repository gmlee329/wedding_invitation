# 프레시 세이지 스카이 테마 디자인

## 목표

기존 브라운·아이보리 인상을 밝은 하늘색과 싱그러운 초록색 중심의 산뜻한 웨딩 테마로 바꾼다. 사용자가 브라우저 시안에서 선택한 A안의 색상 체계만 적용하며, 현재 청첩장의 글꼴·글자 크기·레이아웃·여백·모서리·애니메이션·영상 동작은 변경하지 않는다.

## 확정 팔레트

- 종이 배경: `#EFFBFD`
- 기본 글자: `#244346`
- 보조 글자: `#6B8586`
- 주요 초록: `#4F8178`
- 옅은 하늘색: `#CDEDF4`
- 연한 세이지: `#B8D8CB`

버튼처럼 밝은 글자가 올라가는 면은 주요 초록과 기본 글자를 혼합해 한 단계 어둡게 사용한다. 이렇게 하면 A안의 인상을 유지하면서 작은 글자의 대비를 확보한다.

## 색상 적용 범위

- `html`, `body`, 인트로 배경과 종이 질감의 기본색을 종이 배경으로 통일한다.
- `Wedding Invitation`, `Invitation`, `Bride & Groom`을 포함한 모든 섹션 중제목은 주요 초록으로 통일한다.
- 기존 브론즈색이 사용된 포커스 외곽선, 카드 라벨, 스토리 연도, 타임라인 점과 강조 요소는 주요 초록 계열로 바꾼다.
- 갈색 계열의 사진 자리 및 미디어 폴백 그라데이션은 옅은 하늘색과 연한 세이지 조합으로 바꾼다.
- 버튼과 진한 배경은 주요 초록에서 파생한 짙은 초록을 사용한다.
- 구분선, 그림자, 오버레이는 기본 글자색에서 파생해 차갑고 깨끗한 톤으로 맞춘다.
- 흰색 반투명 표면은 유지하되 종이 배경과 어울리도록 투명도만 기존 구조 안에서 사용한다.

## 유지 범위

- Allura, Georgia 및 시스템 한글 글꼴 구성을 그대로 유지한다.
- 모든 폰트 크기, 굵기, 자간, 행간을 그대로 유지한다.
- 섹션 순서, 카드 구조, 모서리 반경, 간격과 반응형 레이아웃을 그대로 유지한다.
- 인트로 교차 페이드, 본문 등장 모션과 재생 버튼 동작을 그대로 유지한다.
- 영상과 이미지 파일을 재생성하거나 수정하지 않는다.
- 브라우저 비교 시안의 카드 형태, 사진 프레임, 이탤릭 스타일은 실제 청첩장에 적용하지 않는다.

## 구현

- `WEDDING_CONFIG.theme`와 초기 `:root` 색상값을 동일하게 바꿔 첫 렌더링과 JavaScript 초기화 후의 색이 달라지지 않게 한다.
- `bronze`라는 색상 토큰은 제거하고 `green`, `sky`, `softGreen`처럼 실제 역할을 드러내는 토큰으로 교체한다.
- 기존 하드코딩된 브라운·아이보리 RGB 및 16진수 색상을 새 토큰이나 새 팔레트 값으로 치환한다.
- 색상 외 CSS 선언은 변경하지 않는다.

## 검증

- 테스트에서 확정 팔레트와 새 토큰이 런타임에 적용되는지 확인한다.
- 이전 브라운·아이보리 색상값과 `bronze` 토큰이 배포 HTML에 남지 않았는지 확인한다.
- 기존 글꼴·타이포그래피·레이아웃 핵심 선언이 유지되는지 회귀 테스트로 확인한다.
- 모바일 375×812 화면에서 배경, 중제목, 버튼, 카드, 타임라인, 폴백 이미지의 색상을 시각적으로 확인한다.
- 기존 웹 테스트와 영상 테스트를 실행해 테마 변경이 재생 및 접근성 흐름에 영향을 주지 않았는지 확인한다.
