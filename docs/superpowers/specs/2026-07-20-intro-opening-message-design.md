# 인트로 시작 문구 및 지연 재생 설계

## 목표

모바일 청첩장에 진입하면 인트로 영상의 첫 화면 위에 시작 문구를 먼저 보여준다. 문구를 약 1초간 유지한 뒤 자연스럽게 페이드 아웃하고, 페이드가 끝난 시점에 영상을 0초부터 음소거 재생한다.

## 설정 계약

모든 수정 지점은 `index.html` 상단의 `WEDDING_CONFIG.intro`에 둔다.

- `names`: 첫째 줄 `규민 ♡ 사라` (색이 채워지지 않은 선형 하트 문자)
- `message`: 둘째 줄 `결혼 여정을 시작합니다.`
- `messageHoldMs`: 페이드 시작 전 문구 유지 시간, 기본값 `1000`
- `messageFadeMs`: 문구 페이드 시간, 기본값 `600`
- 기존 `video`, `poster`, `muted`, `fallbackDelayMs` 설정은 유지한다.

기존 `eyebrow`와 `title`은 새 문구 설정으로 대체한다. 이름과 안내 문구를 별도 변수로 두어 어느 화면 정보인지 쉽게 식별하고 각각 수정할 수 있게 한다.

## 화면 및 재생 흐름

1. 인트로 레이어와 영상 소스를 즉시 준비하되 자동 재생하지 않는다.
2. 영상의 포스터 또는 준비된 첫 프레임 위에 두 줄 문구를 표시한다.
3. `messageHoldMs`가 지나면 문구에 페이드 상태를 적용한다.
4. `messageFadeMs`가 지나 문구가 사라지면 영상을 0초부터 재생한다.
5. 영상 종료 시 기존과 동일하게 인트로를 닫고 청첩장 본문을 표시한다.

문구가 사라지기 전에도 `SKIP`, 음소거 전환, `Escape` 동작은 유지한다. 진행 표시 애니메이션은 실제 영상 재생이 시작된 뒤 동작하게 한다.

## 상태 및 예외 처리

- `SKIP`, `Escape`, 영상 종료 또는 오류로 인트로가 닫히면 문구·재생 예약 타이머를 모두 해제한다.
- 지연된 콜백은 인트로가 이미 종료됐거나 DOM에서 사라졌다면 영상을 재생하지 않는다.
- 영상 경로가 비어 있거나 재생이 거부되면 기존 미디어 오류 안내와 자동 종료 흐름을 사용한다.
- 숫자가 아닌 시간값은 안전한 기본값으로 보정하고, 음수는 `0`으로 제한한다.
- 모션 감소 환경에서는 1초 유지 후 페이드 애니메이션 없이 바로 문구를 숨기고 영상을 재생한다.

## 접근성

- 두 줄 문구는 하나의 인트로 제목으로 읽히도록 연결한다.
- 페이드가 끝난 문구는 보조 기술의 탐색 대상에서도 제외한다.
- 본문 `inert`, 포커스 복원, 스킵 버튼 초기 포커스 등 기존 접근성 동작은 유지한다.

## 검증

- 설정값과 정확한 기본 문구가 상단에 존재하는지 확인한다.
- 인트로 렌더 직후 `video.play()`가 호출되지 않는지 확인한다.
- 유지 시간 후 페이드 상태가 적용되고, 페이드 시간 후 한 번만 재생되는지 확인한다.
- 스킵 후 예약 콜백을 실행해도 영상이 재생되지 않는지 확인한다.
- 기존 인트로 종료·오류·섹션 토글 및 단일 `index.html` 계약의 회귀 여부를 전체 테스트로 확인한다.
- 로컬 `file://` 환경에서 실제 `assets/video/intro.mp4` 재생과 시각적 전환을 확인한다.
