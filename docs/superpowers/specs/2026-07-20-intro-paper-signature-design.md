# 인트로 종이 배경·서명체·원본 영상 설계

## 목표

인트로 시작 화면을 청첩장 본문과 같은 종이색과 질감으로 맞춘다. 시작 문구는 첨부 이미지와 유사한 영문 서명체로 표시하고, 문구가 사라진 뒤에는 어둡게 만드는 요소 없이 원본 밝기의 영상을 재생한다.

## 확정된 시각 방향

- 시작 문구는 위에서부터 `Gyumin`, `&`, `Sara`를 세로로 배치한다.
- `Gyumin`과 `Sara`는 사용자가 선택한 A안인 Google Fonts의 `Allura`를 사용한다.
- `&`는 첨부 이미지처럼 이름보다 작게 표시하고 세리프체를 사용한다.
- `결혼 여정을 시작합니다.`는 가독성을 위해 기존 산세리프체를 유지한다.
- 시작 화면의 글자색은 본문과 같은 `--ink`를 사용한다.

## 상단 설정 계약

`index.html` 상단의 `WEDDING_CONFIG.intro`에서 다음 값을 각각 수정할 수 있어야 한다.

- `groomName: 'Gyumin'`: 첫째 서명 이름
- `connector: '&'`: 두 이름 사이 기호
- `brideName: 'Sara'`: 둘째 서명 이름
- `message: '결혼 여정을 시작합니다.'`: 서명 아래 안내 문구
- 기존 `messageHoldMs: 1000`, `messageFadeMs: 600`, `video`, `poster`, `muted`, `fallbackDelayMs`는 유지한다.

기존의 한 문자열 `names` 설정은 위 세 필드로 대체한다. 어느 위치에 사용되는 값인지 이름만으로 식별할 수 있게 한다.

## 폰트 공급

`https://fonts.googleapis.com/css2?family=Allura&display=swap` 스타일시트를 `<head>`에서 불러온다. 외부 JavaScript나 빌드 도구는 추가하지 않는다.

- 인터넷 연결이 있으면 모든 지원 브라우저에서 동일한 Allura 서명체를 표시한다.
- 인터넷 연결이 없거나 CDN 로딩에 실패해도 `cursive` 대체 글꼴로 문구와 모든 기능을 계속 표시한다.
- 직접 `file://`로 열거나 GitHub Pages에서 열 때 동일한 상대 경로와 실행 구조를 유지한다.

## 배경과 영상 레이어

### 문구 표시 단계

1. 인트로 컨테이너가 청첩장 본문의 `.invitation-page`와 같은 `--paper` 배경색, 세 개의 종이 질감 그라데이션, 배경 크기를 사용한다.
2. 영상 소스는 미리 불러오지만 `is-video-playing` 전까지 `opacity: 0`과 `visibility: hidden`으로 가린다.
3. 종이 배경 위에 서명 문구를 1000ms 표시하고 기존 600ms 페이드를 실행한다.

### 영상 재생 단계

1. 문구 페이드가 끝나면 기존 로직대로 영상을 0초로 맞추고 `play()`를 호출한다.
2. 영상의 `playing` 이벤트가 발생하면 `is-video-playing` 상태를 적용한다.
3. 이 상태에서 영상은 전환용 반투명 효과 없이 즉시 `opacity: 1`, `visibility: visible`이 된다.
4. 영상의 `object-fit: cover`, 스킵, 음소거 전환, 진행 표시, 종료 동작은 유지한다.

### 제거할 어둡기 원인

- `.intro`의 짙은 녹색 방사형 그라데이션과 `#171814` 배경을 제거한다.
- `.intro-video`의 상시 `opacity: 0.78`을 제거한다.
- 영상 전체 위에 놓인 `.intro-shade` 요소와 어두운 선형 그라데이션 스타일을 제거한다.
- 미디어 오류 상태에서 영상을 `opacity: 0.16`으로 만드는 규칙을 제거한다. 오류 시 영상은 숨겨진 상태로 남고 종이 배경과 기존 오류 안내를 표시한다.

## 컨트롤 가독성

영상 전체를 어둡게 하지 않는다. 대신 `SOUND`와 `SKIP` 버튼에만 `--paper` 기반의 반투명 배경과 `--ink` 글자색을 사용한다. 진행선도 `--ink` 기반 색으로 바꿔 종이 배경과 밝은 영상 모두에서 식별할 수 있게 한다.

버튼의 기존 44px 이상 터치 영역, 포커스 표시, 접근성 이름과 눌림 상태는 유지한다.

## 접근성과 동작

- 하나의 `h1` 안에 신랑 이름, `&`, 신부 이름, 안내 문구를 순서대로 둬 보조 기술이 자연스럽게 읽도록 한다.
- 문구 페이드 완료 후에는 제목 전체를 `aria-hidden="true"`로 처리한다.
- 모션 감소 환경에서는 1000ms 표시 후 600ms 페이드 지연만 생략하고 즉시 영상을 표시·재생한다.
- `SKIP`, `Escape`, 오류 또는 종료 시 기존처럼 예약 타이머와 영상을 정리하고 본문 포커스를 복원한다.
- CDN 폰트 실패는 인트로 재생 실패로 취급하지 않는다.

## 검증 기준

- 설정에 `Gyumin`, `&`, `Sara`, 안내 문구가 별도 필드로 존재하는지 확인한다.
- Google Fonts Allura URL만 허용된 외부 스타일시트이며 외부 JavaScript가 없는지 확인한다.
- `.intro-shade`, 어두운 인트로 배경, 영상 상시 `opacity: 0.78`이 제거됐는지 확인한다.
- 렌더 직후 영상은 숨겨지고 재생 호출은 발생하지 않는지 확인한다.
- 1000ms와 600ms가 지난 뒤 `play()`가 한 번 호출되고, `playing` 이벤트 후 영상 표시 상태가 적용되는지 확인한다.
- 스킵·오류·모션 감소·섹션 토글의 기존 테스트를 유지한다.
- 전체 Node 테스트, `git diff --check`, 직접 `file://` 모바일 확인을 실행한다.
- 직접 확인에서는 종이 배경의 질감 일치, A안 서명체, 원본 영상 밝기, 밝은 장면 위 컨트롤 가독성을 확인한다.
