# 고급스러운 본문 등장 모션 디자인

## 목표

청첩장 글씨가 급하게 튀어 오르는 느낌을 줄이고, 천천히 페이드인되면서
부드럽게 올라오도록 한다. 사용자가 `index.html` 상단에서 숫자만 바꿔
전체 등장 속도를 손쉽게 조정할 수 있어야 한다.

## 확인된 원인

- 현재 `cubic-bezier(0.22, 1, 0.36, 1)`은 초반 이동이 빠른 ease-out 계열이라
  1.6~1.8초의 지속시간보다 더 급하게 느껴진다.
- 시작 이동 거리 44~52px가 커서 글씨가 빠르게 솟는 인상을 강화한다.
- 지속시간과 거리가 각 CSS 규칙에 직접 적혀 있어 사용자가 한 곳에서
  조정하기 어렵다.

## 승인된 디자인

CSS 상단 `:root`에 다음 세 변수를 둔다.

- `--reveal-duration: 2400ms`: 페이드인과 상승에 공통으로 적용할 시간.
  숫자가 클수록 더 천천히 나타난다는 한글 주석을 붙인다.
- `--reveal-distance: 32px`: 글씨가 시작할 아래쪽 거리.
  숫자가 작을수록 움직임이 차분하다는 주석을 붙인다.
- `--reveal-body-delay: 300ms`: 중제목 뒤 본문이 시작하는 간격.
  숫자가 클수록 본문이 늦게 시작한다는 주석을 붙인다.

헤더와 본문은 같은 지속시간과 이동 거리를 사용하고, 본문에만 지연을
적용한다. easing은 초반과 끝이 모두 완만한 `ease-in-out`을 사용한다.

## 유지 범위

- 인트로 종료 뒤 reveal이 시작되는 현재 초기화 순서를 유지한다.
- `prefers-reduced-motion: reduce` 사용자는 즉시 내용을 볼 수 있게 유지한다.
- 글꼴, 색상, 레이아웃, 이미지와 다른 인터랙션은 변경하지 않는다.
- 새 JavaScript 설정이나 의존성을 추가하지 않는다.
- `assets/video/intro.original.mp4`는 추적하거나 변경하지 않는다.

## 검증

- 정적 테스트로 세 변수가 상단에 선언되고 실제 reveal CSS에서 사용되는지 확인한다.
- 기존 하드코딩된 1600ms, 1800ms, 52px, 44px 값이 제거됐는지 확인한다.
- 모바일 브라우저에서 계산된 지속시간이 2.4초, 이동 거리가 32px,
  본문 지연이 0.3초인지 확인한다.
- 인트로가 열린 동안 글씨는 숨겨져 있고, 종료 뒤 중간 시점에서 opacity와
  transform이 진행 중이며, 종료 뒤에는 최종 상태인지 확인한다.
- 전체 자동 테스트와 `git diff --check`를 실행한다.
